# ייבוא האתר ל-Elementor

הקובץ `ronis-elementor.json` הוא תבנית דף (Page template) ל-Elementor Pro.

## ייבוא
1. הורד את `ronis-elementor.json` למחשב.
2. בלוח הבקרה של וורדפרס: **Templates ← Saved Templates ← Import Templates**, ובחר את הקובץ.
3. צור דף חדש, פתח אותו ב-Elementor, וב-**Add Template** (תיקייה) בחר "RONIS - דף הבית" ← Insert.
4. בהגדרות הדף (Page Settings ← Layout) בחר **Elementor Canvas** (אם לא נבחר אוטומטית), כדי שכותרת הערכה לא תתחרה בתפריט הקבוע.

## מה בפנים
- **תפריט + מסך ראשון (Hero):** שני ווידג'טי HTML. כאן נמצאים העיצוב, הדמות, אפקט היציאה מהמסך והפאראלקס. את הטקסטים משנים בתוך ה-HTML.
- **אודות, פרויקטים, קריאה לפעולה, פוטר:** קונטיינרים וווידג'טים רגילים, ניתנים לעריכה ויזואלית. הכרטיסים משתמשים ב-Motion Effects של Pro (גלילה אנכית).
- **ווידג'ט HTML אחרון:** סקריפט קטן לאפקטי ה-Hero. אל תמחק אותו.

## אחרי הייבוא
- **תמונות:** שלוש התמונות (`skyline.jpg`, `pavement.jpg`, `hero-character.png`) נטענות כרגע מכתובת תצוגה מקדימה של Netlify, שעלולה להיעלם. העלה אותן לספריית המדיה והחלף את הכתובות בווידג'ט ה-HTML של ה-Hero (חפש `netlify.app`). אפשר להריץ מחדש `python3 build_template.py <כתובת בסיס לתמונות>` כדי לייצר קובץ חדש.
- **קישורים:** הקישורים לדף יצירת קשר מצביעים על `/contact/`. התאם לכתובת בפועל.
- **פרויקטים:** שמות הפרויקטים והרקעים הם דוגמאות.
- **טופס יצירת קשר:** הטופס מ-Netlify (`contact.html`) לא חלק מהתבנית. ב-Elementor Pro השתמש בווידג'ט Form.
